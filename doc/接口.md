# 逸刻博客后台 API 接口文档

## 1. 基础说明
- **基础路径 (Base URL)**: `/api/v1`
- **请求数据格式**: `application/json` (文件上传除外)
- **响应格式**: 统一采用如下 JSON 结构
  ```json
  {
    "code": 200,      // 200 成功，其他为错误码
    "message": "success",
    "data": {}        // 具体业务数据
  }
  ```
- **认证方式**: 除登录、注册外，其他接口均需在请求头携带 `Authorization: Bearer <token>`。

---

## 2. 用户模块 (`users`)

### 2.1 用户注册
- **URL**: `/auth/register`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "name": "张三",
    "mail": "zhangsan@example.com",
    "password": "123456"
  }
  ```
- **Response**: `{ "code": 200, "message": "注册成功", "data": { "id": 1, "name": "张三" } }`

### 2.2 用户登录
- **URL**: `/auth/login`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "mail": "zhangsan@example.com",
    "password": "123456"
  }
  ```
- **Response**: `{ "code": 200, "message": "登录成功", "data": { "token": "eyJhb...", "userInfo": {...} } }`

### 2.3 获取个人信息
- **URL**: `/users/profile`
- **Method**: `GET`
- **Response**: 包含 `id`, `name`, `mail`, `imgurl`, `created_at`

### 2.4 修改个人信息
- **URL**: `/users/profile`
- **Method**: `PUT`
- **Body**: `{ "name": "新名字", "imgurl": "https://..." }`

## 3. 文章模块 (`article`, `subset`, `label`)

### 3.1 获取文章列表
- **URL**: `/articles`
- **Method**: `GET`
- **Query 参数**:
  - `page` (默认 1)
  - `pageSize` (默认 10)
  - `subset_id` (分类 ID，非必填)
  - `classify` (文章分类类型，非必填)
  - `state` (状态：0草稿，1已发布)
- **Response**: `{ "list": [...], "total": 100 }`

### 3.2 获取文章详情
- **URL**: `/articles/:id`
- **Method**: `GET`
- **说明**: 每次获取详情时，后端自动将 `views` 字段 +1。

### 3.3 创建文章
- **URL**: `/articles`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "title": "文章标题",
    "subset_id": 1,
    "classify": 1,
    "label": "标签1,标签2",
    "introduce": "文章简介",
    "content": "文章内容",
    "cover": "封面图URL"
  }
  ```

### 3.4 更新文章
- **URL**: `/articles/:id`
- **Method**: `PUT`

### 3.5 删除文章
- **URL**: `/articles/:id`
- **Method**: `DELETE`

### 3.6 分类管理 (`subset`)
- **获取分类列表**: `GET /subsets` (支持按 `classify` 过滤)
- **创建分类**: `POST /subsets` (Body: `subset_name`, `classify`)
- **删除分类**: `DELETE /subsets/:id`

### 3.7 标签管理 (`label`)
- **获取标签列表**: `GET /labels`
- **创建标签**: `POST /labels` (Body: `label_name`, `user_id`)

## 4. 文件模块 (`file`)

### 4.1 上传文件
- **URL**: `/files/upload`
- **Method**: `POST`
- **Content-Type**: `multipart/form-data`
- **Body**:
  - `file`: 二进制文件
  - `subset_id`: 所属分类 ID (可选)
- **说明**: 后端接收文件并保存到本地/对象存储，将记录存入 `file` 表。
- **Response**: 返回 `url`、`file_name`、`format` 等。

### 4.2 获取文件列表
- **URL**: `/files`
- **Method**: `GET`
- **Query**: `subset_id`, `format`, `page`, `pageSize`

### 4.3 删除文件
- **URL**: `/files/:id`
- **Method**: `DELETE`
- **说明**: 需同时删除物理文件及数据库记录。

---

## 5. 评论与点赞模块 (`comment`, `praise`)

### 5.1 获取文章评论列表
- **URL**: `/articles/:articleId/comments`
- **Method**: `GET`
- **Query**: `page`, `pageSize`
- **说明**: 返回评论列表，包含评论者信息（需联查 `users` 表获取 `name` 和 `imgurl`）。

### 5.2 发表评论
- **URL**: `/comments`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "article_id": 1,
    "user_id": 2,
    "content": "写得很棒！"
  }
  ```

### 5.3 删除评论
- **URL**: `/comments/:id`
- **Method**: `DELETE`

### 5.4 投诉评论
- **URL**: `/comments/:id/complain`
- **Method**: `PUT`
- **说明**: 将 `is_complained` 字段更新为 1。

### 5.5 点赞/取消点赞
- **URL**: `/praises`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "article_id": 1,
    "user_id": "2",
    "user_type": 1
  }
  ```
- **说明**: 点赞前先查询 `praise` 表，若已存在则删除记录（取消点赞），否则插入记录。此接口可作为切换（Toggle）接口使用。

## 6. 日记与天气模块 (`diary`, `weather`)

### 6.1 获取日记列表
- **URL**: `/diaries`
- **Method**: `GET`
- **Query**: `page`, `pageSize`, `mood` (心情筛选)

### 6.2 发布日记
- **URL**: `/diaries`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "title": "今天天气不错",
    "content": "去公园散步了...",
    "picture": "图片URL",
    "weather_id": 1,
    "mood": 1
  }
  ```

### 6.3 更新/删除日记
- **更新**: `PUT /diaries/:id`
- **删除**: `DELETE /diaries/:id`

### 6.4 获取天气选项
- **URL**: `/weathers`
- **Method**: `GET`
- **说明**: 获取 `weather` 表中的所有天气数据，供日记下拉选择使用。

---

## 7. 消息与记录模块 (`message`, `record`)

### 7.1 获取私信/通知列表
- **URL**: `/messages`
- **Method**: `GET`
- **Query**: `user_id`, `user_type`, `isread`, `page`, `pageSize`
- **说明**: 联查 `users` 表获取发送者名字和头像。

### 7.2 发送私信/系统通知
- **URL**: `/messages`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "sender_id": 1,
    "user_id": 2,
    "user_type": 1,
    "content": "你好！"
  }
  ```

### 7.3 标记消息已读
- **URL**: `/messages/:id/read`
- **Method**: `PUT`
- **说明**: 将对应消息的 `isread` 字段更新为 1。

### 7.4 获取浏览/操作记录 (`record`)
- **URL**: `/records`
- **Method**: `GET`
- **Query**: `user_id`, `user_type`, `page`, `pageSize`
- **说明**: 获取用户的浏览记录。

### 7.5 新增记录
- **URL**: `/records`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "user_id": "1",
    "user_type": 1,
    "position": "文章标题/URL"
  }
  ```

## 8. 附录：统一错误码规范

| 错误码 | 含义 | 说明 |
| :--- | :--- | :--- |
| 200 | Success | 请求成功 |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未登录或 Token 失效 |
| 403 | Forbidden | 无权限访问该资源 |
| 404 | Not Found | 请求的资源不存在 |
| 500 | Internal Server Error | 服务器内部错误 |

> **⚠️ 注意事项：**
> 1. 所有涉及 `user_id` 的字段（原表中有 `INT` 和 `VARCHAR(100)` 两种类型），在实际开发中建议**统一数据类型**（推荐使用 `INT`），避免联表查询报错。
> 2. 数据库表 `comment` 在 PostgreSQL 中是关键字，执行 SQL 时需要注意使用双引号转义（你提供的建表语句已做处理）。
> 3. 文件上传接口需注意文件大小限制和存储路径配置。
